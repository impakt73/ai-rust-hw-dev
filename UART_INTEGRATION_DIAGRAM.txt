SIGNAL FLOW:

  CPU Write to 0x52000000:
    CPU → Memory Bus → Address Decoder → UART TX Register →
    Baud Generator → Serial Transmitter → uart_tx → usb_tx (M9) →
    FTDI → USB → Host Computer

  Host Computer Write:
    Host → USB → FTDI → usb_rx (P14) → uart_rx →
    Serial Receiver → UART RX Register → CPU Read from 0x52000004
