# VCD Analyzer Tool

The `analyze_vcd` binary is a command-line tool for analyzing VCD (Value Change Dump) files generated by the RISC-V CPU simulator.

## Features

- Parse VCD files and extract simulation statistics
- Count total clock cycles, instructions executed, memory accesses
- Analyze program counter (PC) range and unique values
- Calculate performance metrics (CPI, IPC)
- Display comprehensive statistics in human-readable format

## Usage

```bash
# Build the analyzer
cargo build --package cpu-sim --bin analyze_vcd

# Run analysis on a VCD file
./target/debug/analyze_vcd <path-to-vcd-file>

# Example
./target/debug/analyze_vcd /tmp/println_test.vcd
```

## Output

The analyzer provides the following statistics:

- **Simulation Time**: Maximum timestamp and total clock cycles
- **Execution Statistics**: Instructions executed, memory reads/writes
- **Program Counter Range**: Min/max PC, unique PC values
- **Performance Metrics**: CPI (Cycles Per Instruction), IPC (Instructions Per Cycle)

## Implementation

The analyzer is implemented using:
- **vcd crate**: For parsing VCD file format
- **Custom statistics tracking**: For counting signal transitions and values
- **Timestamp-based cycle counting**: Uses VCD timestamps to determine cycle count
