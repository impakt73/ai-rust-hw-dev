# sim-view Testing Implementation Plan

**Technical Plan for Approach 1: Headless Golden File Testing with Buffer Capture**  
**Date:** 2026-01-20  
**Status:** Planning  
**Based on:** docs/research/automated-testing-for-realtime-multimedia.md

## Executive Summary

This document provides a detailed technical implementation plan for adding comprehensive automated testing to the `sim-view` crate using **Approach 1: Headless Golden File Testing with Buffer Capture** from the research document. This approach separates multimedia data generation from presentation, enabling fast, deterministic, and CI-friendly testing without requiring actual display servers or audio devices.

## Testing Requirements

### Core Data Integrity Requirements

1. **Video Data Integrity**: Validate that video frames rendered by the simulator match expected output
2. **Audio Data Integrity**: Validate that audio samples generated by the simulator match expected output

### Additional Testing Requirements

3. **Frame Duplication Prevention**: Verify that we don't present the same frame twice consecutively
4. **Frame Pacing Verification**: Verify that frame presentations are properly paced according to target FPS
5. **Audio-Video Synchronization**: Verify that audio and video data are properly synchronized

### Testing Approach

These requirements will be addressed through:
- **Snapshot testing** using the `insta` crate for golden file comparison
- **Architecture refactoring** to expose raw buffers for headless testing
- **Property-based testing** for invariant validation (frame pacing, no duplicates, etc.)
- **Timing validation** for synchronization checks

## Current Architecture Analysis

### Existing Components

```
sim-view/
├── src/
│   ├── main.rs                  # CLI entry point
│   ├── viewer.rs                # Main viewer loop & state machine
│   ├── video_window.rs          # minifb wrapper (video rendering)
│   ├── audio_stream.rs          # cpal wrapper (audio playback)
│   └── simulator_controller.rs  # CPU simulation controller
```

### Current Data Flow

```
SimulatorController
    │
    ├─► get_video_frame() ──► VideoWindow::process_video_frame()
    │                             │
    │                             └─► framebuffer (Vec<u32>)
    │                                     │
    │                                     └─► minifb::Window::update()
    │
    └─► get_audio_samples() ──► AudioStream::push_samples()
                                    │
                                    └─► sample_buffer (VecDeque<i16>)
                                            │
                                            └─► cpal::Stream (hardware)
```

### Key Observations

1. **Good separation exists**: `SimulatorController` already separates data generation from presentation
2. **Buffer access needed**: `VideoWindow` has internal `framebuffer: Vec<u32>`, but it's private
3. **Audio buffer is thread-safe**: `AudioStream` uses `Arc<Mutex<VecDeque<i16>>>` internally
4. **State machine is well-defined**: `ViewerState` enum with clear transitions
5. **No frame tracking**: Current implementation doesn't track frame sequence or timing metadata

```rust
use crate::traits::{VideoRenderer, ViewerEvent};
use cpu_sim::{VideoConfig, VideoFormat};
use std::collections::VecDeque;

/// Headless video renderer that captures frames to memory
pub struct HeadlessVideoRenderer {
    /// Current framebuffer (ARGB8888 format)
    framebuffer: Vec<u32>,
    
    /// Frame dimensions
    width: usize,
    height: usize,
    
    /// Frame history for testing (limited size)
    frame_history: VecDeque<VideoFrame>,
    
    /// Maximum frames to keep in history
    max_history: usize,
    
    /// Frame sequence counter
    frame_count: u64,
    
    /// Active state
    active: bool,
}

/// Captured frame with metadata
#[derive(Clone, Debug)]
pub struct VideoFrame {
    /// Frame sequence number
    pub sequence: u64,
    
    /// Frame data (ARGB8888)
    pub data: Vec<u32>,
    
    /// Dimensions at time of capture
    pub width: usize,
    pub height: usize,
    
    /// Timestamp (for testing only)
    pub timestamp: std::time::Instant,
}

impl HeadlessVideoRenderer {
    pub fn new(width: usize, height: usize) -> Self {
        Self::with_history(width, height, 100)
    }
    
    pub fn with_history(width: usize, height: usize, max_history: usize) -> Self {
        Self {
            framebuffer: vec![0xFF000000u32; width * height],
            width,
            height,
            frame_history: VecDeque::new(),
            max_history,
            frame_count: 0,
            active: true,
        }
    }
    
    /// Get the frame history for testing
    pub fn get_frame_history(&self) -> &VecDeque<VideoFrame> {
        &self.frame_history
    }
    
    /// Clear frame history
    pub fn clear_history(&mut self) {
        self.frame_history.clear();
    }
    
    /// Compute checksum of current framebuffer
    pub fn compute_checksum(&self) -> u64 {
        use std::collections::hash_map::DefaultHasher;
        use std::hash::{Hash, Hasher};
        let mut hasher = DefaultHasher::new();
        self.framebuffer.hash(&mut hasher);
        hasher.finish()
    }
    
    /// Convert frame data based on VideoFormat
    fn convert_frame(&mut self, data: &[u8], format: VideoFormat) -> Result<(), String> {
        match format {
            VideoFormat::Rgba8 => self.convert_rgba8(data),
            VideoFormat::Rgb8 => self.convert_rgb8(data),
            VideoFormat::Rgb565 => self.convert_rgb565(data),
            VideoFormat::R8 => self.convert_r8(data),
        }
    }
    
    // Conversion methods (same as VideoWindow)
    fn convert_rgba8(&mut self, data: &[u8]) -> Result<(), String> {
        let pixel_count = self.width * self.height;
        if data.len() < pixel_count * 4 {
            return Err("Frame data too small for RGBA8 format".to_string());
        }

        for i in 0..pixel_count {
            let r = data[i * 4] as u32;
            let g = data[i * 4 + 1] as u32;
            let b = data[i * 4 + 2] as u32;
            let a = data[i * 4 + 3] as u32;
            self.framebuffer[i] = (a << 24) | (r << 16) | (g << 8) | b;
        }
        Ok(())
    }
    
    fn convert_rgb8(&mut self, data: &[u8]) -> Result<(), String> {
        let pixel_count = self.width * self.height;
        if data.len() < pixel_count * 3 {
            return Err("Frame data too small for RGB8 format".to_string());
        }

        for i in 0..pixel_count {
            let r = data[i * 3] as u32;
            let g = data[i * 3 + 1] as u32;
            let b = data[i * 3 + 2] as u32;
            self.framebuffer[i] = 0xFF000000 | (r << 16) | (g << 8) | b;
        }
        Ok(())
    }
    
    fn convert_rgb565(&mut self, data: &[u8]) -> Result<(), String> {
        let pixel_count = self.width * self.height;
        if data.len() < pixel_count * 2 {
            return Err("Frame data too small for RGB565 format".to_string());
        }

        for i in 0..pixel_count {
            let pixel = u16::from_le_bytes([data[i * 2], data[i * 2 + 1]]);
            let r5 = ((pixel >> 11) & 0x1F) as u8;
            let g6 = ((pixel >> 5) & 0x3F) as u8;
            let b5 = (pixel & 0x1F) as u8;
            let r8 = (r5 << 3) | (r5 >> 2);
            let g8 = (g6 << 2) | (g6 >> 4);
            let b8 = (b5 << 3) | (b5 >> 2);
            self.framebuffer[i] = 0xFF000000 | (u32::from(r8) << 16) | (u32::from(g8) << 8) | u32::from(b8);
        }
        Ok(())
    }
    
    fn convert_r8(&mut self, data: &[u8]) -> Result<(), String> {
        let pixel_count = self.width * self.height;
        if data.len() < pixel_count {
            return Err("Frame data too small for R8 format".to_string());
        }

        for (fb_pixel, &gray) in self.framebuffer.iter_mut().zip(data.iter()).take(pixel_count) {
            let gray32 = u32::from(gray);
            *fb_pixel = 0xFF000000 | (gray32 << 16) | (gray32 << 8) | gray32;
        }
        Ok(())
    }
}

impl VideoRenderer for HeadlessVideoRenderer {
    fn process_frame(&mut self, data: &[u8], config: &VideoConfig) -> Result<(), String> {
        let new_width = config.width as usize;
        let new_height = config.height as usize;
        
        // Resize if dimensions changed
        if new_width != self.width || new_height != self.height {
            self.width = new_width;
            self.height = new_height;
            self.framebuffer.resize(new_width * new_height, 0xFF000000);
        }
        
        // Convert frame data to ARGB8888
        self.convert_frame(data, config.format)?;
        
        Ok(())
    }
    
    fn update(&mut self) -> Result<(), String> {
        // Capture current frame to history
        let frame = VideoFrame {
            sequence: self.frame_count,
            data: self.framebuffer.clone(),
            width: self.width,
            height: self.height,
            timestamp: std::time::Instant::now(),
        };
        
        self.frame_history.push_back(frame);
        self.frame_count += 1;
        
        // Limit history size
        while self.frame_history.len() > self.max_history {
            self.frame_history.pop_front();
        }
        
        Ok(())
    }
    
    fn get_framebuffer(&self) -> Option<&[u32]> {
        Some(&self.framebuffer)
    }
    
    fn dimensions(&self) -> (usize, usize) {
        (self.width, self.height)
    }
    
    fn is_active(&self) -> bool {
        self.active
    }
}
```

```c
// Generates a simple 4-color quadrant pattern
// Top-left: Red, Top-right: Green, Bottom-left: Blue, Bottom-right: Yellow

#include <stdint.h>

#define VIDEO_CONFIG_ADDR 0x80001000
#define VIDEO_BUFFER_ADDR 0x80002000
#define TOHOST_ADDR       0x80000000

#define WIDTH 320
#define HEIGHT 240

void write_video_config(uint32_t width, uint32_t height, uint32_t format) {
    volatile uint32_t *config = (volatile uint32_t *)VIDEO_CONFIG_ADDR;
    config[0] = width;
    config[1] = height;
    config[2] = format;  // 1 = RGB8
}

void draw_pattern() {
    volatile uint8_t *buffer = (volatile uint8_t *)VIDEO_BUFFER_ADDR;
    
    for (int y = 0; y < HEIGHT; y++) {
        for (int x = 0; x < WIDTH; x++) {
            int idx = (y * WIDTH + x) * 3;
            
            if (y < HEIGHT/2 && x < WIDTH/2) {
                // Top-left: Red
                buffer[idx + 0] = 255;
                buffer[idx + 1] = 0;
                buffer[idx + 2] = 0;
            } else if (y < HEIGHT/2 && x >= WIDTH/2) {
                // Top-right: Green
                buffer[idx + 0] = 0;
                buffer[idx + 1] = 255;
                buffer[idx + 2] = 0;
            } else if (y >= HEIGHT/2 && x < WIDTH/2) {
                // Bottom-left: Blue
                buffer[idx + 0] = 0;
                buffer[idx + 1] = 0;
                buffer[idx + 2] = 255;
            } else {
                // Bottom-right: Yellow
                buffer[idx + 0] = 255;
                buffer[idx + 1] = 255;
                buffer[idx + 2] = 0;
            }
        }
    }
}

int main() {
    // Configure video output
    write_video_config(WIDTH, HEIGHT, 1);
    
    // Draw pattern
    draw_pattern();
    
    // Signal completion
    volatile uint32_t *tohost = (volatile uint32_t *)TOHOST_ADDR;
    *tohost = 1;
    
    return 0;
}
```

```rust
fn test_no_duplicate_frames_in_animation() {
    let mut video = HeadlessVideoRenderer::with_history(320, 240, 100);
    let mut controller = SimulatorController::new().unwrap();
    
    // Load a program that animates (e.g., moving sprite or changing colors)
    controller.load_elf("test_programs/sim_view_tests/animated_pattern.elf").unwrap();

    let mut cycles = 0;

                }
                
                if result.tohost_value.is_some() {

                }
            }

    let history = video.get_frame_history();

            frame1.sequence, frame2.sequence

    }
    
    // Verify we captured multiple frames
    assert!(history.len() > 10, "Should have captured multiple frames");

fn test_static_frames_are_identical() {
```

### Phase 5: Frame Pacing Verification Tests

**File:** `sim-view/tests/frame_pacing_tests.rs` (new file)

```rust
use sim_view::headless_video::HeadlessVideoRenderer;
use sim_view::traits::VideoRenderer;
use cpu_sim::SimulatorController;
use std::time::Duration;

#[test]
fn test_frame_timing_consistency() {
    let mut video = HeadlessVideoRenderer::with_history(320, 240, 120);
    let mut controller = SimulatorController::new().unwrap();
    
    // Load animated test program
    controller.load_elf("test_programs/sim_view_tests/animated_pattern.elf").unwrap();
    
    // Simulate at ~60 FPS target
    const TARGET_FPS: u64 = 60;
    const FRAME_DURATION_MS: u64 = 1000 / TARGET_FPS;
    const INSTRUCTIONS_PER_FRAME: u64 = 10000;
    
    let start_time = std::time::Instant::now();
    let mut frame_count = 0;
    const MAX_FRAMES: u64 = 60; // 1 second worth of frames
    
    while frame_count < MAX_FRAMES {
        let frame_start = std::time::Instant::now();
        
        // Step simulation
        match controller.step_instructions(INSTRUCTIONS_PER_FRAME) {
            Ok(result) => {
                if let Some((frame_data, config)) = controller.get_video_frame() {
                    video.process_frame(&frame_data, &config).unwrap();
                    video.update().unwrap();
                    frame_count += 1;
                }
                
                if result.tohost_value.is_some() {
                    break;
                }
            }
            Err(_) => break,
        }
        
        // Frame pacing simulation
        let elapsed = frame_start.elapsed();
        if elapsed < Duration::from_millis(FRAME_DURATION_MS) {
            std::thread::sleep(Duration::from_millis(FRAME_DURATION_MS) - elapsed);
        }
    }
    
    // Verify frame timing
    let history = video.get_frame_history();
    
    if history.len() < 2 {
        panic!("Not enough frames captured for timing analysis");
    }
    
    // Calculate inter-frame intervals
    let mut intervals: Vec<Duration> = Vec::new();
    for window in history.iter().collect::<Vec<_>>().windows(2) {
        let dt = window[1].timestamp.duration_since(window[0].timestamp);
        intervals.push(dt);
    }
    
    // Verify intervals are consistent (within tolerance)
    let avg_interval_ms: f64 = intervals.iter()
        .map(|d| d.as_millis() as f64)
        .sum::<f64>() / intervals.len() as f64;
    
    // Target: 16.67ms per frame at 60 FPS
    // Allow ±5ms tolerance for test environment variability
    assert!(
        (avg_interval_ms - FRAME_DURATION_MS as f64).abs() < 5.0,
        "Average frame interval {}ms is outside tolerance of {}ms ±5ms",
        avg_interval_ms, FRAME_DURATION_MS
    );
    
    // Verify no individual frame is drastically off
    for (i, interval) in intervals.iter().enumerate() {
        let interval_ms = interval.as_millis();
        assert!(
            (interval_ms as i64 - FRAME_DURATION_MS as i64).abs() < 10,
            "Frame {} interval {}ms is outside tolerance of {}ms ±10ms",
            i, interval_ms, FRAME_DURATION_MS
        );
    }
}
```

```rust
use sim_view::headless_audio::HeadlessAudioPlayer;

#[test]
fn test_av_sync_basic() {
    let mut video = HeadlessVideoRenderer::with_history(320, 240, 100);

    const MAX_CYCLES: u64 = 100_000;
    
    let video_start_time: Option<std::time::Instant> = None;
    let audio_start_time: Option<std::time::Instant> = None;
    
    while cycles < MAX_CYCLES {
        match controller.step_instructions(1000) {
            Ok(result) => {
                cycles += 1000;

                if let Some((frame_data, config)) = controller.get_video_frame() {
                    video.process_frame(&frame_data, &config).unwrap();
                    video.update().unwrap();
                }
                
                // Process audio
                let samples = controller.get_audio_samples(4096);
                if !samples.is_empty() {
                    audio.push_samples(&samples);
                }
                
                if result.tohost_value.is_some() {
                    break;
                }
            }
            Err(_) => break,
        }
    }
    
    // Verify that video and audio started at roughly the same time
    // This is a simplified test - real implementation would need markers
    
    let video_frames = video.get_frame_history();
    let audio_samples = audio.total_samples_received();
    
    // Verify we got both audio and video
    assert!(video_frames.len() > 0, "Should have video frames");
    assert!(audio_samples > 0, "Should have audio samples");
    
    // For a 60fps video and 44.1kHz audio, the ratio should be:
    // audio_samples / video_frames ≈ 44100 / 60 = 735 samples per frame
    
    let samples_per_frame = audio_samples as f64 / video_frames.len() as f64;
    
    // Allow reasonable tolerance (±20%)
    const EXPECTED_SAMPLES_PER_FRAME: f64 = 735.0; // 44100Hz / 60fps
    const TOLERANCE: f64 = 0.20; // 20%
    
    let lower_bound = EXPECTED_SAMPLES_PER_FRAME * (1.0 - TOLERANCE);
    let upper_bound = EXPECTED_SAMPLES_PER_FRAME * (1.0 + TOLERANCE);
    
    assert!(
        samples_per_frame >= lower_bound && samples_per_frame <= upper_bound,
        "Audio/Video ratio out of sync: {} samples/frame (expected {}±{})",
        samples_per_frame, EXPECTED_SAMPLES_PER_FRAME, TOLERANCE
    );
}

#[test]
fn test_av_sync_timing_markers() {
    // More sophisticated test using timing markers
    // Test program should generate:
    // - Visual flash at t=0ms, t=500ms, t=1000ms
    // - Audio beep at t=0ms, t=500ms, t=1000ms
    
    let mut video = HeadlessVideoRenderer::with_history(320, 240, 200);
    let mut audio = HeadlessAudioPlayer::new();
    let mut controller = SimulatorController::new().unwrap();
    
    controller.load_elf("test_programs/sim_view_tests/av_sync_markers.elf").unwrap();
    
    // Track when markers occur
    let mut video_markers = Vec::new();
    let mut audio_markers = Vec::new();
    
    let mut cycles = 0;
    const MAX_CYCLES: u64 = 200_000;
    let mut last_brightness = 0u32;
    let mut last_audio_level = 0i16;
    
    while cycles < MAX_CYCLES {
        match controller.step_instructions(1000) {
            Ok(result) => {
                cycles += 1000;
                
                // Detect video flash (brightness spike)
                if let Some((frame_data, config)) = controller.get_video_frame() {
                    video.process_frame(&frame_data, &config).unwrap();
                    video.update().unwrap();
                    
                    if let Some(fb) = video.get_framebuffer() {
                        // Calculate average brightness
                        let brightness: u32 = fb.iter()
                            .map(|&pixel| {
                                let r = (pixel >> 16) & 0xFF;
                                let g = (pixel >> 8) & 0xFF;
                                let b = pixel & 0xFF;
                                (r + g + b) / 3
                            })
                            .sum::<u32>() / fb.len() as u32;
                        
                        // Detect flash (significant brightness increase)
                        if brightness > last_brightness + 100 {
                            video_markers.push(std::time::Instant::now());
                        }
                        last_brightness = brightness;
                    }
                }
                
                // Detect audio beep (amplitude spike)
                let samples = controller.get_audio_samples(4096);
                if !samples.is_empty() {
                    audio.push_samples(&samples);
                    
                    // Check for amplitude spike
                    let max_amplitude = samples.iter().map(|&s| s.abs()).max().unwrap_or(0);
                    
                    if max_amplitude > last_audio_level + 1000 {
                        audio_markers.push(std::time::Instant::now());
                    }
                    last_audio_level = max_amplitude;
                }
                
                if result.tohost_value.is_some() {
                    break;
                }
            }
            Err(_) => break,
        }
    }
    
    // Verify that audio and video markers occurred at the same times (±50ms)
    assert_eq!(video_markers.len(), audio_markers.len(), 
               "Should have same number of A/V sync markers");
    
    for (i, (v_time, a_time)) in video_markers.iter().zip(audio_markers.iter()).enumerate() {
        let diff = if v_time > a_time {
            v_time.duration_since(*a_time)
        } else {
            a_time.duration_since(*v_time)
        };
        
        assert!(
            diff.as_millis() < 50,
            "Marker {} sync error: {}ms (video and audio should be within 50ms)",
            i, diff.as_millis()
        );
    }
}
```

```rust
// Property: Frame sequence numbers are monotonically increasing
proptest! {
    #[test]
    fn test_frame_sequence_monotonic(
        frame_count in 1usize..100,
    ) {
        use sim_view::headless_video::HeadlessVideoRenderer;
        use sim_view::traits::VideoRenderer;
        use cpu_sim::{VideoConfig, VideoFormat};
        
        let mut renderer = HeadlessVideoRenderer::with_history(320, 240, frame_count);
        
        // Generate dummy frames
        let config = VideoConfig {
            width: 320,
            height: 240,
            format: VideoFormat::R8,
        };
        
        let dummy_frame = vec![0u8; 320 * 240];
        
        for _ in 0..frame_count {
            renderer.process_frame(&dummy_frame, &config).unwrap();
            renderer.update().unwrap();
        }
        
        // Verify sequences are monotonically increasing
        let history = renderer.get_frame_history();
        for window in history.iter().collect::<Vec<_>>().windows(2) {
            prop_assert!(window[1].sequence > window[0].sequence,
                        "Frame sequences not monotonic: {} -> {}",
                        window[0].sequence, window[1].sequence);
        }
    }
}

// Property: Audio buffer never exceeds maximum size
proptest! {
    #[test]
    fn test_audio_buffer_bounded(
        sample_count in 1usize..100000,

        use sim_view::headless_audio::HeadlessAudioPlayer;
        use sim_view::traits::AudioPlayer;
        
        let max_buffer = 48000;

        // Buffer should never exceed maximum
```

## Risk Mitigation

### Potential Challenges

1. **Platform-specific differences**
   - **Risk:** Checksums may differ across platforms
   - **Mitigation:** Use perceptual hashing instead of exact byte comparison
   - **Mitigation:** Document expected variations, allow tolerance ranges

2. **Golden file storage**
   - **Risk:** Large snapshot files increase repository size
   - **Mitigation:** Use checksums instead of full frame data
   - **Mitigation:** Limit frame history size in tests
   - **Mitigation:** Use git-lfs for large binary snapshots if needed

3. **Test flakiness**
   - **Risk:** Timing-based tests may be unreliable
   - **Mitigation:** Use generous tolerance ranges
   - **Mitigation:** Retry flaky tests with exponential backoff
   - **Mitigation:** Separate timing tests from correctness tests

4. **Refactoring effort**
   - **Risk:** Significant code changes required
   - **Mitigation:** Phased rollout, maintain backward compatibility
   - **Mitigation:** Incremental refactoring with continuous validation
