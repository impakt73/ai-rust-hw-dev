# RTL Modifications Required

## Overview

This document provides detailed RTL modifications required to convert the single-cycle CPU to a multi-cycle implementation. Each section includes the specific code changes needed.

## Module Change Summary

| Module | Modification Level | Changes Required |
|--------|-------------------|------------------|
| `top.sv` | **Major** | FSM, latching registers, control logic |
| `decoder.sv` | **None** | No changes |
| `alu.sv` | **None** | No changes |
| `regfile.sv` | **None** | No changes (write enable is already gated) |

## top.sv Modifications

### 1. Add New Output Signals

Add the instruction completion signal to the module interface:

```systemverilog
module top (
    input  logic        clk,
    input  logic        rst_n,
    input  logic [31:0] boot_addr,
    
    // Instruction memory interface (unchanged)
    output logic [31:0] imem_addr,
    input  logic [31:0] imem_data,
    
    // Data memory interface (unchanged)
    output logic [31:0] dmem_addr,
    output logic [31:0] dmem_wdata,
    input  logic [31:0] dmem_rdata,
    output logic        dmem_we,
    output logic        dmem_re,
    output logic [1:0]  dmem_size,
    
    // System control signals (modified)
    output logic        halted,
    output logic        instr_complete,  // NEW: High for one cycle when instruction completes
    
    // Debug outputs (unchanged)
    output logic [31:0] debug_rs1_data,
    output logic [31:0] debug_rs2_data,
    output logic [31:0] debug_rd_data
);
```

```systemverilog
    typedef enum logic [3:0] {

        S_FETCH      = 4'b0001,
        S_DECODE     = 4'b0010,
        S_EXECUTE    = 4'b0011,
        S_MEM_ADDR   = 4'b0100,
        S_MEM_READ   = 4'b0101,
        S_MEM_WRITE  = 4'b0110,
        S_WRITEBACK  = 4'b0111,
        S_BRANCH     = 4'b1000,
        S_CSR        = 4'b1001,
        S_HALT       = 4'b1010
```


### 5. Modify Instruction Assignment

Change to use latched instruction in later states:

```systemverilog
    // Use imem_data in FETCH, use latched IR in other states
    // Decoder always sees the current instruction being processed
    assign instruction = (current_state == S_FETCH) ? imem_data : ir;
```

### 6. Add State Register

Add the FSM state register:

```systemverilog
    // State Register
    always_ff @(posedge clk or negedge rst_n) begin
        if (!rst_n) begin
            current_state <= S_IDLE;
        end else begin
            current_state <= next_state;
        end
    end
```

### 7. Add Next State Logic

Add the next state combinational logic:

```systemverilog
    // Next State Logic
    always_comb begin
        next_state = current_state;  // Default: hold
        
        case (current_state)
            S_IDLE: begin
                next_state = S_FETCH;
            end
            
            S_FETCH: begin
                next_state = S_DECODE;
            end
            
            S_DECODE: begin
                // Decode instruction type and branch to appropriate state
                if (is_ecall || is_ebreak) begin
                    next_state = S_HALT;
                end else if (is_fence) begin
                    next_state = S_FETCH;  // FENCE is NOP, go back to fetch
                end else if (is_csr) begin
                    next_state = S_CSR;
                end else if (mem_read || mem_write) begin
                    next_state = S_MEM_ADDR;
                end else if (branch) begin
                    next_state = S_BRANCH;
                end else begin
                    // R-type, I-type arithmetic, LUI, AUIPC, JAL, JALR
                    next_state = S_EXECUTE;
                end
            end
            
            S_EXECUTE: begin
                next_state = S_WRITEBACK;
            end
            
            S_MEM_ADDR: begin
                if (mem_read_latched) begin
                    next_state = S_MEM_READ;
                end else begin
                    next_state = S_MEM_WRITE;
                end
            end
            
            S_MEM_READ: begin
                next_state = S_WRITEBACK;
            end
            
            S_MEM_WRITE: begin
                next_state = S_FETCH;
            end
            
            S_WRITEBACK: begin
                next_state = S_FETCH;
            end
            
            S_BRANCH: begin
                next_state = S_FETCH;
            end
            
            S_CSR: begin
                next_state = S_WRITEBACK;
            end
            
            S_HALT: begin
                next_state = S_HALT;  // Stay halted
            end
            
            default: begin
                next_state = S_IDLE;
            end
        endcase
    end
```

### 8. Add Control Signal Output Logic

Add the control signal generation:

```systemverilog
    // Control Signal Output Logic
    always_comb begin
        // Default all control signals to inactive
        ir_write = 1'b0;
        a_reg_write = 1'b0;
        b_reg_write = 1'b0;
        alu_out_write = 1'b0;
        mdr_write = 1'b0;
        pc_write = 1'b0;
        reg_write_en = 1'b0;
        decode_latch = 1'b0;
        dmem_we = 1'b0;
        dmem_re = 1'b0;
        instr_complete = 1'b0;
        
        case (current_state)
            S_FETCH: begin
                ir_write = 1'b1;
            end
            
            S_DECODE: begin
                a_reg_write = 1'b1;
                b_reg_write = 1'b1;
                decode_latch = 1'b1;
                // FENCE completes here
                if (is_fence) begin
                    pc_write = 1'b1;
                    instr_complete = 1'b1;
                end
            end
            
            S_EXECUTE: begin
                alu_out_write = 1'b1;
            end
            
            S_MEM_ADDR: begin
                alu_out_write = 1'b1;
            end
            
            S_MEM_READ: begin
                dmem_re = 1'b1;
                mdr_write = 1'b1;
            end
            
            S_MEM_WRITE: begin
                dmem_we = 1'b1;
                pc_write = 1'b1;
                instr_complete = 1'b1;
            end
            
            S_WRITEBACK: begin
                reg_write_en = 1'b1;
                pc_write = 1'b1;
                instr_complete = 1'b1;
            end
            
            S_BRANCH: begin
                pc_write = 1'b1;
                instr_complete = 1'b1;
            end
            
            S_CSR: begin
                // CSR update happens in this state
                // Writeback follows
            end
            
            S_HALT: begin
                // Stay halted, no signals
            end
            
            default: begin
                // All signals inactive
            end
        endcase
    end
```

### 9. Add Latching Logic

```systemverilog
    // Instruction Register Latch
    always_ff @(posedge clk or negedge rst_n) begin
        if (!rst_n) begin
            ir <= 32'h0;
        end else if (ir_write) begin
            ir <= imem_data;
        end
    end
    
    // A Register Latch (rs1 data)
    always_ff @(posedge clk or negedge rst_n) begin
        if (!rst_n) begin
            a_reg <= 32'h0;
        end else if (a_reg_write) begin
            a_reg <= rs1_data;
        end
    end
    
    // B Register Latch (rs2 data)
    always_ff @(posedge clk or negedge rst_n) begin
        if (!rst_n) begin
            b_reg <= 32'h0;
        end else if (b_reg_write) begin
            b_reg <= rs2_data;
        end
    end
    
    // ALU Output Register Latch
    always_ff @(posedge clk or negedge rst_n) begin
        if (!rst_n) begin
            alu_out_reg <= 32'h0;
        end else if (alu_out_write) begin
            alu_out_reg <= alu_result;
        end
    end
    
    // Memory Data Register Latch
    always_ff @(posedge clk or negedge rst_n) begin
        if (!rst_n) begin
            mdr <= 32'h0;

            imm_j_latched <= 32'h0;

            reg_write_latched <= 1'b0;
            mem_write_latched <= 1'b0;
            mem_read_latched <= 1'b0;
            mem_to_reg_latched <= 1'b0;
            branch_latched <= 1'b0;
            jump_latched <= 1'b0;
            is_ecall_latched <= 1'b0;
            is_ebreak_latched <= 1'b0;
            is_fence_latched <= 1'b0;
            is_csr_latched <= 1'b0;
            csr_rdata_latched <= 32'h0;
        end else if (decode_latch) begin
            opcode_latched <= opcode;
            rd_latched <= rd;
            rs1_latched <= rs1;
            rs2_latched <= rs2;
            funct3_latched <= funct3;
            funct7_latched <= funct7;
```

### 10. Modify ALU Input Selection

Change ALU inputs to use latched values:

```systemverilog
    // ALU Source A Selection
    always_comb begin
        case (current_state)
            S_EXECUTE: begin
                // For LUI: use 0, for AUIPC/JAL: use PC
                if (opcode_latched == 7'b0110111) begin  // LUI
                    alu_a = 32'h0;
                end else if (opcode_latched == 7'b0010111 || jump_latched) begin  // AUIPC or JAL/JALR
                    alu_a = pc;
                end else begin
                    alu_a = a_reg;
                end
            end
            S_MEM_ADDR: begin
                alu_a = a_reg;  // Base address from rs1
            end
            S_BRANCH: begin
                alu_a = a_reg;  // For comparison
            end
            default: begin
                alu_a = a_reg;
            end
        endcase
    end
    
    // ALU Source B Selection
    always_comb begin
        case (current_state)
            S_EXECUTE: begin
                // Select immediate or register based on instruction type
                if (opcode_latched == 7'b0110111) begin  // LUI
                    alu_b = imm_u_latched;
                end else if (opcode_latched == 7'b0010111) begin  // AUIPC
                    alu_b = imm_u_latched;
                end else if (jump_latched) begin  // JAL/JALR: compute return address
                    alu_b = 32'd4;
                end else if (alu_src_latched) begin
                    alu_b = imm_i_latched;
                end else begin
                    alu_b = b_reg;
                end
            end
            S_MEM_ADDR: begin
                // Use imm_i for load, imm_s for store
                alu_b = mem_write_latched ? imm_s_latched : imm_i_latched;
            end
            S_BRANCH: begin
                alu_b = b_reg;  // For comparison
            end
            default: begin
                alu_b = b_reg;
            end
        endcase
    end
```

### 11. Modify PC Update Logic

Change PC update to work with FSM:

```systemverilog
    // Next PC Calculation
    logic [31:0] next_pc_value;
    
    always_comb begin
        next_pc_value = pc + 32'd4;  // Default: sequential
        
        case (current_state)
            S_BRANCH: begin
                if (take_branch)
                    next_pc_value = pc + imm_b_latched;
                else
                    next_pc_value = pc + 32'd4;
            end
            
            S_WRITEBACK: begin
                if (opcode_latched == 7'b1101111) begin  // JAL
                    next_pc_value = pc + imm_j_latched;
                end else if (opcode_latched == 7'b1100111) begin  // JALR
                    next_pc_value = (a_reg + imm_i_latched) & ~32'h1;
                end else begin
                    next_pc_value = pc + 32'd4;
                end
            end
            
            default: begin
                next_pc_value = pc + 32'd4;
            end
        endcase
    end
    
    // PC Register
    always_ff @(posedge clk or negedge rst_n) begin
        if (!rst_n) begin
            pc <= boot_addr;
        end else if (pc_write && !halted) begin
            pc <= next_pc_value;
        end
    end
```

### 12. Modify Branch Decision Logic

Change to use latched values:

```systemverilog
    // Branch Decision (use latched values)
    always_comb begin
        take_branch = 1'b0;
        if (branch_latched) begin
            case (funct3_latched)
                3'b000: take_branch = (a_reg == b_reg);             // BEQ
                3'b001: take_branch = (a_reg != b_reg);             // BNE
                3'b100: take_branch = ($signed(a_reg) < $signed(b_reg));  // BLT
                3'b101: take_branch = ($signed(a_reg) >= $signed(b_reg)); // BGE
                3'b110: take_branch = (a_reg < b_reg);              // BLTU
                3'b111: take_branch = (a_reg >= b_reg);             // BGEU
                default: take_branch = 1'b0;
            endcase
        end
    end
```

### 14. Modify Write-back Data Selection

Change to use latched values and registers:

```systemverilog
    // Write-back Data Selection
    always_comb begin
        if (opcode_latched == 7'b0110111) begin  // LUI
            rd_data = alu_out_reg;
        end else if (opcode_latched == 7'b0010111) begin  // AUIPC
            rd_data = alu_out_reg;
        end else if (jump_latched) begin  // JAL/JALR
            rd_data = alu_out_reg;  // Return address (PC + 4)
        end else if (is_csr_latched) begin
            rd_data = csr_rdata_latched;
        end else if (mem_to_reg_latched) begin  // Load
            rd_data = mdr;
        end else begin  // ALU result
            rd_data = alu_out_reg;
        end
    end
```

### 17. Modify CSR Logic

Change CSR update to occur in S_CSR state:

```systemverilog
    // CSR Register Update
    always_ff @(posedge clk or negedge rst_n) begin
        if (!rst_n) begin
            for (int i = 0; i < 4096; i++) begin
                csr_file[i] = 32'h0;
            end
        end else if (current_state == S_CSR && is_csr_latched) begin
            case (funct3_latched)
                3'b001: csr_file[imm_i_latched[11:0]] <= a_reg;  // CSRRW
                3'b010: if (rs1_latched != 5'b0) 
                        csr_file[imm_i_latched[11:0]] <= csr_rdata_latched | a_reg;  // CSRRS
                3'b011: if (rs1_latched != 5'b0) 
                        csr_file[imm_i_latched[11:0]] <= csr_rdata_latched & ~a_reg; // CSRRC
                3'b101: csr_file[imm_i_latched[11:0]] <= {27'b0, rs1_latched};  // CSRRWI
                3'b110: if (rs1_latched != 5'b0) 
                        csr_file[imm_i_latched[11:0]] <= csr_rdata_latched | {27'b0, rs1_latched};  // CSRRSI
                3'b111: if (rs1_latched != 5'b0) 
                        csr_file[imm_i_latched[11:0]] <= csr_rdata_latched & ~{27'b0, rs1_latched}; // CSRRCI
                default: ;
            endcase
        end
    end
```

## No Changes Required

### decoder.sv

The decoder module requires **no changes**. It operates purely combinationally and will:
- Run in the DECODE state
- Have its outputs latched by the top module
- Continue to work identically to the single-cycle version

### alu.sv

The ALU module requires **no changes**. It operates purely combinationally and will:
- Receive inputs from the FSM-controlled muxes
- Produce results used in different cycles
- Continue to work identically to the single-cycle version

### regfile.sv

The register file module requires **no changes**. It already:
- Has async read (works immediately in any state)
- Has sync write with enable (FSM controls when writes happen)
- Properly enforces x0 = 0
