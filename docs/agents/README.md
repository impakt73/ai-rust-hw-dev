# Agent Documentation

This directory contains documentation files specifically designed for AI coding agents.

These files provide detailed guidelines, conventions, best practices, and technical context that agents should follow when working on this codebase. They are typically referenced by the `AGENTS.md` file in the repository root.

The documentation here helps ensure consistent, high-quality code generation by providing agents with domain-specific knowledge about RISC-V architecture, SystemVerilog development, Rust verification patterns, and project-specific conventions.
